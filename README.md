# E-Commerce Platform

A full-featured e-commerce platform built with the MERN stack (MongoDB, Express, React, Node.js). This platform allows users to browse products, add items to the cart, and complete orders with secure payment.

---

## Features

- User Authentication (JWT-based login and registration)
- Product Search and Filters
- Shopping Cart with Quantity Management
- Checkout with Payment Gateway Integration (e.g., Stripe/PayPal)
- Admin Dashboard for Product Management

2. **Set up the backend:**

   cd backend
3. **Install dependencies:**
   npm install
4. **Add your environment variables in a .env file:**
   MONGO_URI=your-mongodb-uri
   JWT_SECRET=your-jwt-secret
   STRIPE_KEY=your-stripe-key
5. **Start the server:**
   npm start

6. **Navigate to the frontend folder:**
   cd frontend
7. **Install dependencies:**
   npm install

   npm start
9. **Open your browser at http://localhost:3000.**
